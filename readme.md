# 🎲 Streamlit 로또 번호 생성기

Streamlit을 활용하여 구현한 간단하고 직관적인 로또 번호 생성기 웹 애플리케이션입니다.

## 📌 주요 기능
- **랜덤 번호 생성**: `로또번호 생성` 버튼 클릭 시 1~45 사이의 중복 없는 숫자 6개를 랜덤 추출 및 자동 오름차순 정렬
- **최대 5개 세트 유지**: 번호 생성 버튼을 누를 때마다 최대 5개 세트까지 화면에 보관 (5개 초과 시 가장 오래된 세트 자동 삭제)
- **실제 로또 공 색상 적용**:
  - `1 ~ 10`: 노란색 🟡
  - `11 ~ 20`: 파란색 🔵
  - `21 ~ 30`: 빨간색 🔴
  - `31 ~ 40`: 회색 ⚪
  - `41 ~ 45`: 녹색 🟢
- **초기화 기능**: 생성된 번호 목록을 한 번에 리셋 가능

---

## 🚀 시작하기

### 1. 레포지토리 클론 / 다운로드
프로젝트 파일을 다운로드하거나 클론합니다.

### 2. 의존성 패키지 설치
`requirements.txt`에 명시된 패키지(Streamlit)를 설치합니다.

```bash
pip install -r requirements.txt
```

### 3. 애플리케이션 실행
터미널에서 아래 명령어를 입력하여 Streamlit 앱을 실행합니다.

```bash
streamlit run app.py
```

실행 후 브라우저에서 `http://localhost:8501` 주소로 자동 연결됩니다.

## 🛠️ 기술 스택
- **Python** (3.8+)
